🚀 STEP 1: INSTALL DOCKER ON YOUR LOCAL PC

┌─ For Windows ─────────────────────────────────────────────────────┐
│ 1. Download Docker Desktop:                                       │
│    https://www.docker.com/products/docker-desktop                 │
│                                                                    │
│ 2. Run the installer                                              │
│ 3. Restart your computer                                          │
│ 4. Start Docker Desktop                                           │
│ 5. Verify installation:                                           │
│    - Open PowerShell or Command Prompt                            │
│    - Run: docker --version                                        │
│    - Run: docker compose version                                  │
└────────────────────────────────────────────────────────────────────┘

┌─ For Ubuntu/Linux ────────────────────────────────────────────────┐
│ Open terminal and run:                                            │
│                                                                    │
│   curl -fsSL https://get.docker.com -o get-docker.sh             │
│   sudo sh get-docker.sh                                           │
│   sudo usermod -aG docker $USER                                   │
│   sudo systemctl enable docker                                    │
│   sudo systemctl start docker                                     │
│                                                                    │
│ Log out and back in, then verify:                                │
│   docker --version                                                │
│   docker compose version                                          │
└────────────────────────────────────────────────────────────────────┘

┌─ For macOS ───────────────────────────────────────────────────────┐
│ 1. Download Docker Desktop:                                       │
│    https://www.docker.com/products/docker-desktop                 │
│                                                                    │
│ 2. Install and start Docker Desktop                               │
│ 3. Verify in Terminal:                                            │
│    docker --version                                               │
│    docker compose version                                         │
└────────────────────────────────────────────────────────────────────┘

🚀 STEP 3: RUN AUTOMATED INSTALLATION

On your local PC, in the CMMS folder:

┌─ Windows (PowerShell or Command Prompt) ──────────────────────────┐
│ cd C:\CMMS                                                         │
│ install.sh                                                         │
│                                                                    │
│ (Or if that doesn't work, use manual commands from Step 4)        │
└────────────────────────────────────────────────────────────────────┘

┌─ Linux/Mac (Terminal) ────────────────────────────────────────────┐
│ cd ~/CMMS                                                          │
│ chmod +x install.sh                                               │
│ ./install.sh                                                       │
└────────────────────────────────────────────────────────────────────┘

⏱️ Wait 5-10 minutes for first-time installation

═══════════════════════════════════════════════════════════════════════

⚙️ STEP 4: MANUAL INSTALLATION (If Step 3 doesn't work)

In the CMMS folder, run these commands:

┌────────────────────────────────────────────────────────────────────┐
│ docker compose down                                                │
│ docker compose build --no-cache                                   │
│ docker compose up -d                                               │
└────────────────────────────────────────────────────────────────────┘

🔧 TROUBLESHOOTING

Problem: "Login failed. Please try again"
Solution:
   docker compose restart backend
   docker compose logs backend

Problem: "docker: command not found"
Solution:
   - Make sure Docker Desktop is running (Windows/Mac)
   - Restart Docker service (Linux): sudo systemctl start docker

Problem: "port is already allocated"
Solution:
   - Stop other services using port 80
   - Or change port in docker-compose.yml

Problem: Can't access from other computers
Solution:
   - Check firewall allows port 80
   - Windows: New-NetFirewallRule -DisplayName "CMMS" -Direction Inbound -Protocol TCP -LocalPort 80 -Action Allow
   - Linux: sudo ufw allow 80/tcp
