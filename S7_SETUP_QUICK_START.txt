STEP 2: CONFIGURE TAG MAPPINGS
══════════════════════════════════════════════════════════════════════

  You need your PLC tag addresses from STEP 7 or TIA Portal.

  Option A - Edit template (Recommended):
  ----------------------------------------
    1. Open: opc-service\tag_mapping_template.py
    2. Replace example addresses with your actual PLC tags:

       Asset ID 1 (Hammer Mill Motor):
         running: 'DB1.DBX0.0'  <- Replace with your tag
         trip:    'DB1.DBX0.1'  <- Replace with your tag
         off:     'DB1.DBX0.2'  <- Replace with your tag

       Asset ID 2 (Hammer Mill):
         running: 'DB1.DBX1.0'  <- Replace with your tag
         trip:    'DB1.DBX1.1'  <- Replace with your tag
         off:     'DB1.DBX1.2'  <- Replace with your tag

    3. Save the file
    4. Run: python apply_tag_config.py
    5. Run: python setup_s7_tags.py


  Option B - Edit directly:
  -------------------------
    1. Open: opc-service\setup_s7_tags.py
    2. Find TAG_MAPPINGS = [] (around line 84)
    3. Uncomment example and add your addresses
    4. Save and run: python setup_s7_tags.py

TROUBLESHOOTING:
══════════════════════════════════════════════════════════════════════

  Issue: "snap7 library not installed"
  Solution:
    python diagnose_snap7.py
    install_snap7_windows.bat


  Issue: "Could not connect to PLC"
  Check:
    1. ping 192.168.10.10 (network connectivity)
    2. PLC IP address is correct (192.168.10.10)
    3. Rack/Slot is correct (Rack 0, Slot 3)
    4. PLC is powered on and online
    5. Firewall allows port 102


  Issue: "Tags not updating"
  Check:
    1. Tag addresses are correct in setup_s7_tags.py
    2. Tags exist in PLC program
    3. Check s7_service.py output for errors
    4. Verify in TIA Portal/STEP 7 that tags are accessible


  Issue: Wrong status (shows off when running)
  Solution:
    Set 'invert_logic': True in tag mapping


COMMON PLC TAG FORMATS:
══════════════════════════════════════════════════════════════════════

  Data Block Bits (most common):
    DB1.DBX0.0  - Data Block 1, Byte 0, Bit 0
    DB1.DBX0.1  - Data Block 1, Byte 0, Bit 1
    DB2.DBX10.5 - Data Block 2, Byte 10, Bit 5

  Memory Bits:
    M0.0, M0.1, M1.0

  Input/Output Bits:
    I0.0, Q0.0


WHERE TO FIND TAG ADDRESSES:
══════════════════════════════════════════════════════════════════════

  1. Connect to PLC with STEP 7 or TIA Portal
  2. Open PLC program
  3. Look for Symbol Table or Tag Table
  4. Search for "Motor" or "Hammer" or equipment names
  5. Note the addresses (DB number, byte, bit)
