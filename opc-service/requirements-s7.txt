# Note: Also requires snap7 library (C library)
# Install instructions:
#
# Windows:
#   Download snap7.dll from https://github.com/Davinci/snap7/releases
#   Place in C:\Windows\System32 or same folder as script
#
# Linux (Ubuntu/Debian):
#   sudo apt-get install libsnap7-1 libsnap7-dev
#
# Linux (from source):
#   git clone https://github.com/Davinci/snap7.git
#   cd snap7/build/unix
#   make -f x86_64_linux.mk
#   sudo make -f x86_64_linux.mk install
#
# macOS:
#   brew install snap7
